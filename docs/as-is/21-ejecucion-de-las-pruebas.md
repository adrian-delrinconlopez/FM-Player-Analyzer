## Reproducibilidad de la verificación

Windows x86-64, compilación de referencia con GCC 13.1.0 y Qt 6.8.3. Se usó CTest con tres procesos y salida detallada en caso de error. El directorio de compilación se creó fuera del repositorio. Para auditar el original desde un árbol ya compilado, ejecutar `ctest --test-dir <directorio-de-compilación> --output-on-failure -j3`. La verificación de otra implementación puede usar directamente las entradas y resultados Markdown.

Los dos casos opcionales se omitieron porque FM27_TEST_SAVE no designaba una partida real. Los casos de selección, visibilidad, recálculo e importación con datos sintéticos sí se ejecutaron.
