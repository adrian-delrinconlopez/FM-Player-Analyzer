# Decisiones confirmadas del producto

Autoridad: encargo de Fase B y aclaraciones del propietario del 21, el 22 y el 23 de noviembre de 2026. En este documento **CONFIRMADA** significa aprobada por el propietario. Una solución técnica candidata, una referencia comunitaria y el resultado de una prueba requieren registros distintos. Para cambiar una decisión, anotar fecha, motivo, IDs afectados y efecto en pruebas e históricos en el [registro de cambios](CHANGELOG-TO-BE.md).

| ID | Decisión CONFIRMADA | Consecuencia verificable |
|---|---|---|
| DP-01 | Producto nuevo, exclusivamente para Football Manager 27. | Toda importación, catálogo, perfil y táctica se vincula a FM27. Se excluye compatibilidad con FM24. |
| DP-02 | Windows 11 x64, C#, .NET 10 LTS, WinUI 3 nativo con XAML y Windows App SDK compatible. | HTML/CSS/JS queda reservado al prototipo. Electron, Tauri, React, Dioxus, WPF, Blazor Hybrid y WebView2 quedan descartados como base de UI. |
| DP-03 | SQLite es la fuente persistente local. Soporte para carreras independientes y sesiones concurrentes con el juego. | Aislar identidades y series, acotar memoria y evaluar volúmenes superiores a 100.000 registros. |
| DP-04 | La obtención de datos de FM27 es de solo lectura. Se admite evaluar un enfoque híbrido que combine BepInEx y lectura de la memoria del juego donde aporte valor. Quedan descartadas la lectura de .fm y la modificación del juego. | Antes de habilitar una vía para un campo, validar compatibilidad, identidad, exactitud y visibilidad. La elección por campo y la adopción del enfoque híbrido quedan abiertas. |
| DP-05 | Juego limpio por defecto. CA y PA deshabilitados, habilitación expresa con advertencia. | El permiso afecta a todas las superficies. Los campos dependen de disponibilidad validada. Ojeo y enmascaramiento tienen controles independientes del permiso de CA/PA. |
| DP-06 | ChatGPT es el único proveedor inicial y su uso es opcional. El motor local calcula indicadores. | Sin red, cuenta ni modelo se puede analizar, planificar, comparar y exportar. Las herramientas sólo acceden a proyecciones autorizadas. |
| DP-07 | Recursos locales en una carpeta graphics seleccionada por el usuario. | Acceso de lectura, asociación por ID y carga bajo demanda. Se excluye redistribuir paquetes de terceros. |
| DP-08 | Castellano para la documentación y primera interfaz. Nomenclatura, grupos y orden oficiales españoles de FM27. | Datos sin verificar se marcan pendientes. Inglés seleccionable previsto para segunda entrega. |
| DP-09 | Prototipo HTML/CSS/JS interactivo, autónomo, ficticio, anterior a la UI final. | Fase B entrega sus especificaciones; la revisión precede al inicio del prototipo y la validación visual precede a implementar la UI definitiva. |
| DP-10 | Git y GitHub Spec Kit, Codex y/o Copilot, una solución .slnx para VS Code y Visual Studio Enterprise. | Los comandos de compilación y prueba se pueden ejecutar sin un IDE. El propietario puede dirigir cada paso. |
| DP-11 | Conservar algoritmos valiosos y explicar las diferencias. Preferencias deportivas configurables. | Calidad, rol, táctica, filosofía y conveniencia económica se muestran como indicadores diferenciados. |
| DP-12 | Permitir exportar tablas seleccionadas de la aplicación, tanto de datos disponibles como de resultados generados, preferentemente a Excel (.xlsx), con CSV como alternativa. | Como casos iniciales, exportar los atributos de la plantilla propia o de una lista de jugadores. Respetar el ámbito, las columnas y la visibilidad autorizados. |

| DP-13 | Comparar calidad actual y potencial por puesto y rol para cada fase. La proyección basada en CA y PA evalúa familiaridad de 20. | Exigir ambos permisos y fuente acreditada. Comparar porcentajes en pp. La función de desarrollo y el horizonte requieren validación en Q-17. |
| DP-14 | Las tablas de jugadores permiten configurar columnas, orden y valoración de rol. Las principales ofrecen «Exportar a Excel». | La descarga XLSX conserva ámbito, filtros, orden, columnas visibles, contexto y política. Las variantes visuales requieren elección del propietario. |
| DP-15 | La v1 de FM27 completa el recorrido plantilla real → valoración actual y potencial por fase → XI y diagnóstico → búsqueda y simulación de refuerzo. Incluye familiaridad 20 como escenario, comparación y XLSX. | La [matriz de v1](roadmap/06-alcance-v1.md) fija qué capacidades entran en la entrega. PoC A acredita datos y PoC B acredita el modelo de proyección antes de activar resultados reales. Históricos avanzados, desarrollo temporal, entrenamiento avanzado, Moneyball, ChatGPT y empleados quedan para entregas posteriores. |
| DP-16 | El ojeo conocido es el universo inicial. La exploración mundial requiere activación expresa y cobertura acreditada del universo cargado. El acceso a atributos ocultos o desconocidos dispone de control independiente del universo y de CA/PA. | Cambiar de universo conserva los permisos de campo. Los ámbitos y campos no acreditados muestran su limitación; los filtros, cálculos, índices y exportaciones usan el permiso efectivo. |
