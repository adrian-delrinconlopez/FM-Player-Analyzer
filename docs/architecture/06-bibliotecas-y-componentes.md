# Evaluación de bibliotecas y componentes

Metadatos de paquetes y documentación revisados el 21-11-2026. Las versiones son candidatos reproducibles, no fijaciones aprobadas. El TFM publicado indica compatibilidad de referencia; recursos nativos, XAML, recorte, despliegue e interacción con el SDK elegido requieren prueba. Las estimaciones de coste son cualitativas hasta PC-04/05/07. Registrar tamaño del paquete instalado, memoria privada, CPU y fotogramas frente al control base.
