# Compilación, empaquetado y distribución

REQ-TECH-001 y REQ-OPS-001. La entrega se define por commit, versiones de herramientas, SDK/TFM/RID, paquetes bloqueados y manifiesto de licencias. Usar una configuración Release x64 reproducible desde terminal, VS Code y Visual Studio Enterprise. Propuesta: global.json y gestión central de versiones en la fase de implementación. Especificar el parche exacto verificado en el acta de PC-04.

**Cadena prevista.** Restaurar en modo bloqueado, compilar la misma solución, ejecutar pruebas de dominio e integración, crear paquete de escritorio y probar instalación/arranque en Windows 11 x64 limpio. Los comandos previstos son dotnet restore con el archivo .slnx, dotnet build en Release x64 y dotnet test sin recompilar los proyectos ya construidos. El manifiesto final definirá rutas y comandos exactos una vez exista la solución. Mantener una configuración de desarrollo que permita ejecutar el núcleo sin FM instalado; compilar el adaptador con referencias legalmente disponibles y versión declarada.

**Distribución propuesta.** MSIX firmado para escritorio y paquete separado del plugin con versiones de protocolo compatibles. Alternativa de escritorio sin empaquetar sólo si un requisito de despliegue la justifica. Evaluar dependencia del Windows App Runtime frente a distribución autocontenida con tamaño y arranque medidos. Instalar/actualizar el plugin requiere acción explícita y documentación de compatibilidad. Probar actualización con copia consistente de datos, rollback de aplicación con esquema compatible y desinstalación diferenciada de datos personales. Sin autoactualización del plugin mientras el juego lo usa.

**Salida.** En máquina limpia: instalar, abrir, crear carrera vacía, importar fixture FM27, cerrar, actualizar y verificar que la misma ficha, configuración y revisión siguen accesibles. Registrar versión de Windows, SDK y runtime, firma y huella de paquetes. El canal de prueba lleva versión única y resultados/omisiones propios; la publicación exige decisión posterior del propietario. [Herramientas de empaquetado](https://github.com/microsoft/WinAppCli)
