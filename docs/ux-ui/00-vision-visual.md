# Visión visual

El puesto de trabajo del analista se organiza alrededor de una carrera, una fecha y una decisión deportiva. En la vista general, situar primero la alineación activa y la carencia que explica la recomendación. Al abrirla se conserva el contexto hasta llegar a la ficha o simulación. En todas las pantallas, el usuario debe poder identificar la partida y la fecha del dato sin abrir Configuración.

Tema oscuro principal, materiales Fluent sobrios y tipografía Segoe UI Variable o Segoe UI. Reservar el color de club y el escudo a su identidad. Usar números alineados, unidades junto al valor, fondos sólidos y jerarquía por tamaño y espaciado. Una alerta indica estado, causa y acción cuando sea posible. Limitar tarjetas a grupos de información que se consultan juntos; las tablas comparables comparten encabezado y alineación.

**Composición de referencia en escritorio.** Navegación a la izquierda; cabecera con carrera y fecha; área de trabajo dominante; inspector lateral opcional para selección, explicación o consulta contextual. Un campo táctico ocupa el área de trabajo y usa el inspector para las opciones del puesto. En una ficha, identidad y fecha preceden a atributos, rol y trayectoria.
